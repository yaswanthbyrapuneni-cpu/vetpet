# MVP scope

## Included

1. Email/password registration and login for owners and doctors
2. Administrator verification of doctor accounts
3. Owner and doctor profiles
4. Multiple pet profiles per owner
5. Doctor availability and appointment booking
6. Appointment approval, cancellation, and completion
7. Medical records and document metadata
8. Consultation notes and structured prescriptions
9. Basic in-app reminders
10. Role-based dashboards and audit events

## Deferred until the core workflow is stable

- payments
- live video and chat
- consultation recording and cloud media storage
- speech-to-text and AI summaries
- push notifications
- analytics dashboards
- disease prediction and image diagnosis

## Definition of done for each feature

A feature is complete only when its database changes, API behavior, client UI,
validation, authorization, and automated tests work together.
